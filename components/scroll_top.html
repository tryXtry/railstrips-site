ScrollTop

ScrollTop gets displayed after a certain scroll position and used to navigates to the top of the page quickly.

Scroll down to see the ScrollTop button...

You've scrolled quite a bit! The button should be visible now.

Usage

<button data-controller="scroll-top"
        data-scroll-top-threshold-value="200"
        data-scroll-top-show-class="translate-y-0 opacity-100"
        data-scroll-top-hide-class="translate-y-10 opacity-0"
        data-action="click->scroll-top#scrollToTop"
        class="fixed bottom-8 right-8 ...">
  <svg ...></svg>
</button>

Attributes

Value Type Default Description
threshold Number 400 Scroll position in pixels to display the button.
behavior String smooth Scrolling behavior (smooth or auto).
target String window The scrolling element. Either "window" or a CSS selector.
