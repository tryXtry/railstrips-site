Slideover

A panel that slides in from the edge of the screen, commonly used for details or actions.

Basic Slideover

Panel Title

This is the content of the slideover. You can put forms, details, or any other content here.

For this demo, we use a simple inline script to find the controller element and call `open()`. In a real app, you might use an outbound action or a global event listener.

Usage

<!-- Controller element (hidden by default) -->
<div data-controller="slideover" class="hidden relative z-50">
  <div data-slideover-target="overlay" class="opacity-0 transition..."></div>
  <div data-slideover-target="panel" class="translate-x-full transition...">
     <button data-action="slideover#close">Close</button>
  </div>
</div>

<!-- Trigger -->
<button data-action="click->slideover#open">Open</button> 
<!-- Note: Button must be inside controller or use events -->
