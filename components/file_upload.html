File Upload

A file upload component with image preview.

Image Upload

or drag and drop

PNG, JPG, GIF up to 10MB

Usage

<div data-controller="file-upload">
  <div data-file-upload-target="placeholder">
     <input type="file" data-file-upload-target="input" data-action="change->file-upload#handleFileSelect">
  </div>
  <img data-file-upload-target="preview" class="hidden">
  <button data-file-upload-target="removeButton" data-action="click->file-upload#remove" class="hidden">Remove</button>
</div>
