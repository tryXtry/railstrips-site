AutoComplete

Input component that provides real-time suggestions when being typed.

Basic

Objects

Usage

<div class="relative" 
     data-controller="autocomplete"
     data-autocomplete-items-value='["Option 1", "Option 2"]'>
  
  <input type="text" 
         data-autocomplete-target="input"
         data-action="input->autocomplete#search keydown->autocomplete#navigate"
         class="form-input">
  
  <ul data-autocomplete-target="results" 
      class="absolute hidden ...">
  </ul>
</div>
